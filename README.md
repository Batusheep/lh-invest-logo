# LH-Invest · Логотип и бренд-материалы

В студии 18 названий и 60 логотипов инвестиционной платформы. Три новых варианта на тему коробочного решения доступны в списке «Готовое сочетание». [Модус · Сгиб М](logo-mockup.html#modus-4) · [Frame · Клапан F](logo-mockup.html#frame-4) · [Основа · Гнездо О](logo-mockup.html#osnova-4).

## Структура

| Файл / папка | Назначение |
|---|---|
| `assets/` | В `round-02/` новые SVG-знаки, композиции с названием и PNG-карточки по названиям. Четыре исходных комплекта лежат в `round-01/` |
| `descriptions/round-02/` | Для каждого названия свой Markdown-файл о нейминге, знаках и выбранной палитре |
| `vendor/` | Внешние библиотеки (`morphicons.js`) |
| `catalog.mjs` | **Каталог материалов** — список кадров и концепций (главный файл для добавления материалов) |
| `build.mjs` | Сборщик: инлайнит всё в один HTML |
| `shell.html` | Каркас страницы (шаблон сборки) |
| `studio.css` / `studio.js` | Стили и логика студии |
| `icon-motion.js` | Анимация иконок |
| `render-markdown.py` | Конвертер `.md` → HTML (используется сборщиком) |
| `brand-review.html` | **Готовый результат сборки** — можно открыть в браузере или выложить на GitHub Pages |
| `logo-mockup.html` | Интерактивная проверка всех 60 знаков в интерфейсе LH-Invest |
| `prototype/lh-invest-interface.html` | Локальная копия исходного интерфейса для независимой пересборки прототипа |
| `create_raster_fixtures.py` | Генератор демо-изображений |

## Как пользоваться

### 1. Открыть готовый просмотр

Открой `brand-review.html` в браузере. Это самодостаточный файл — все изображения и тексты уже внутри (base64), интернет не нужен.

На холсте слева показаны логотип, пример интерфейса и идея выбранного названия. Справа находятся настройки знака, имени и цветов. Кнопка «В избранное» сохраняет сборку для сравнения. В избранном можно открыть сохранённую сборку для редактирования или удалить её. Подборка хранится в локальном хранилище браузера на этом устройстве.

Стрелки сдвигают материалы на одну позицию по кругу. При трёх кадрах после 1, 2, 3 покажутся 2, 3, 4. Закреплённые кадры остаются на своих местах. В режиме сравнения каждая сторона листается отдельно.

### 2. Добавить / заменить материал

1. Положи в папку названия знак `*.svg`, композицию `*-lockup.svg` и карточку `*-board.png` с общей основой имени файла.
2. Добавь в группу названия в `catalog.mjs` заголовок логотипа и путь к файлам без расширения, например `["Складка М", "round-02/modus/modus-2"]`. Описание для всей группы находится в `descriptions/round-02/<id>.md`.
3. Пересобери:
   ```bash
   node build.mjs
   ```
4. `brand-review.html` и `logo-mockup.html` обновятся автоматически.

### 3. Залить на GitHub

```bash
git add .
git commit -m "Краткое описание изменений"
git push
```

После push репозиторий всегда в актуальном состоянии. Если включить GitHub Pages (Settings → Pages → branch: main, folder: `/`), `brand-review.html` будет доступен по прямому URL.

### 4. Пересобрать с нуля

```bash
node build.mjs
```

Сборщик читает `catalog.mjs`, берёт файлы из `assets/` и `descriptions/`, инлайнит всё в `brand-review.html`.

## Требования

- **Node.js** (сборщик)
- **Python** (только для конвертации `.md` в HTML при сборке)

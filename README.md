# LH-Invest · Логотип и бренд-материалы

Студия концепций логотипа для LH-Invest: три варианта (A / B / C), каждый со своим набором материалов.

## Структура

| Файл / папка | Назначение |
|---|---|
| `assets/` | Растровые материалы: `a-01.jpg … c-08.jpg` |
| `descriptions/` | Текстовые описания концепций: `a.md`, `b.md`, `c.md` |
| `vendor/` | Внешние библиотеки (`morphicons.js`) |
| `catalog.mjs` | **Каталог материалов** — список кадров и концепций (главный файл для добавления материалов) |
| `build.mjs` | Сборщик: инлайнит всё в один HTML |
| `shell.html` | Каркас страницы (шаблон сборки) |
| `studio.css` / `studio.js` | Стили и логика студии |
| `icon-motion.js` | Анимация иконок |
| `render-markdown.py` | Конвертер `.md` → HTML (используется сборщиком) |
| `brand-review.html` | **Готовый результат сборки** — можно открыть в браузере или выложить на GitHub Pages |
| `create_raster_fixtures.py` | Генератор демо-изображений |

## Как пользоваться

### 1. Открыть готовый просмотр

Открой `brand-review.html` в браузере. Это самодостаточный файл — все изображения и тексты уже внутри (base64), интернет не нужен.

Стрелки сдвигают материалы на одну позицию по кругу. При трёх кадрах после 1, 2, 3 покажутся 2, 3, 4. Закреплённые кадры остаются на своих местах. В режиме сравнения каждая сторона листается отдельно.

### 2. Добавить / заменить материал

1. Положи файл в нужную папку:
   - картинка → `assets/` (например `a-09.jpg`)
   - описание → `descriptions/` (например `d.md` для новой концепции D)
2. Отредактируй `catalog.mjs` — добавь материал в список `items` соответствующей концепции. Формат:
   ```js
   { key: 'mark', label: 'Компактный знак', file: 'a-09.jpg', background: '#f5f3ef' }
   ```
   `file` — имя в `assets/` или `descriptions/`.
3. Пересобери:
   ```bash
   node build.mjs
   ```
4. `brand-review.html` обновится автоматически.

### 3. Залить на GitHub

```bash
git add .
git commit -m "Краткое описание изменений"
git push
```

После push репозиторий всегда в актуальном состоянии. Если включить GitHub Pages (Settings → Pages → branch: main, folder: `/`), `brand-review.html` будет доступен по прямому URL.

### 4. Пересобрать с нуля

```bash
node build.mjs
```

Сборщик читает `catalog.mjs`, берёт файлы из `assets/` и `descriptions/`, инлайнит всё в `brand-review.html`.

## Требования

- **Node.js** (сборщик)
- **Python** (только для конвертации `.md` в HTML при сборке)

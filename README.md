# Logo · конструктор бренда

Открой `index.html` или `brand-review.html`. В конструкторе можно выбирать готовые сочетания, менять название, знак и цвета, смотреть легенды и сохранять варианты для сравнения. Избранное хранится в браузере.

Порядок добавления имён, знаков, легенд и пресетов описан в [LOGO-WORKFLOW.md](LOGO-WORKFLOW.md). После изменений выполни `node build.mjs`. Исторические правила сохранены в `archive/rules/`.

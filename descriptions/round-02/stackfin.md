# StackFin

## Идея названия

**StackFin** — сочетание английских stack («набор технологических компонентов») и fin как сокращения от finance («финансы»).

Имя показывает платформу как набор технологических компонентов, на основе которого компания создаёт финансовый сервис под своим брендом.

## Короткая формулировка для брендбука

«StackFin — технологическая основа для создания инвестиционного сервиса из согласованных компонентов.»

## Основной слоган

**Технологии для вашего финансового сервиса.**

## Дополнительный слоган

**Соберите свой сервис на общей основе.**

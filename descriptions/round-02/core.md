# Core

## Идея названия

Core — ядро. Технологическая часть находится в центре сервиса, вокруг неё клиент выстраивает продукты и пользовательский опыт. Знак может обозначать и само ядро, и окружающую его оболочку.

## Идеи логотипов

### 1. Косточка

Каплевидная оболочка раскрывается справа. В её вогнутости лежит отдельная круглая косточка. Контраст внешнего среза с гладким центром задаёт характер знака. Зелёная оболочка окружает медную косточку. Тёплый цвет сразу направляет взгляд к ядру.

### 2. Сердечник

Шестигранная оболочка окружает короткий квадратный стержень. Квадрат развернут вершиной вверх и сохраняет собственный силуэт в крупном просвете.

### 3. Внутренняя C

В открытой букве C лежит уменьшенная C с общим центром. Две дуги говорят о внешнем сервисе и внутренней инфраструктуре на языке одного инициала.

# Financial Box

## Идея названия

**Financial Box** — сочетание английских слов *financial* («финансовый») и *box* («коробка»). Название представляет технологическую платформу как коробочное решение для создания финансового сервиса.

Слово *financial* задаёт широкую финансовую рамку, а *box* помогает объяснить формат продукта: компоненты объединены общей основой, которую компания использует для своего сервиса. Название подходит позиционированию, в котором важны деловой характер и понятная структура предложения.

## Короткая формулировка для брендбука

«Financial Box — технологическая платформа для создания финансового сервиса под брендом компании.»

## Основной слоган

**Технологии для вашего финансового сервиса.**

## Дополнительный слоган

**Финансовый сервис на единой основе.**

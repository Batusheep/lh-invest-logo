# InvestMesh

## Идея названия

**InvestMesh** — сочетание английских invest («инвестировать») и mesh («сеть», «сетка»).

Сеть передаёт идею связанных между собой элементов. На общей технологической основе компания создаёт инвестиционный сервис из нужных компонентов.

## Короткая формулировка для брендбука

«InvestMesh — платформа, связывающая компоненты инвестиционного сервиса в общую систему.»

## Основной слоган

**Связанные решения для инвестиций.**

## Дополнительный слоган

**Соберите инвестиционный сервис на общей платформе.**

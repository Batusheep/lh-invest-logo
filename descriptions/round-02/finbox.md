# FinBox

## Идея названия

**FinBox** объединяет *fin* — распространённое сокращение от *finance* («финансы») — и *box* («коробка»). Короткое название связывает финансовую тематику с образом коробочного технологического решения.

Образ коробки помогает представить платформу как общую основу для финансового сервиса, а лаконичная форма делает имя удобным для интерфейса и коммуникаций. Компания использует эту основу для создания сервиса под своим брендом.

## Короткая формулировка для брендбука

«FinBox — технологическая основа для финансового сервиса под вашим брендом.»

## Основной слоган

**Финансовый сервис начинается с FinBox.**

## Дополнительный слоган

**Ваша технология. Ваш бренд.**

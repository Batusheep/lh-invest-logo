# Сохранённый интерфейс-донор

Локальная копия файлов интерфейса из версии `lh-invest-logo-main`, предоставленной пользователем 20.11.2026. `brand-review.html` — сохранённая страница для просмотра, `studio.css`, `studio.js`, `shell.html`, `icon-motion.js` и `vendor/morphicons.js` — исходники для поиска и адаптации компонентов. Это референс, не активная сборка конструктора. Не редактируйте копию для изменений текущей страницы.

Раскрывающийся список: `.concept-menu`, `.concept-select`, `.concept-options`, `.concept-option` в CSS и `choice-menu` в JS. Сравните доступность и управление с требованиями `../../DESIGN.md` перед переносом.

# Новые идеи логотипов

Для каждой новой идеи сохраняйте самостоятельные SVG-знаки в `assets/<name>/`. Задавайте цвета шестизначными HEX-кодами в атрибутах `fill`, чтобы их можно было менять в приложении. Для каждого знака создавайте карточку `<stem>-board.png` и добавляйте запись `[название, путь без расширения, серия]` в соответствующую группу `catalog.mjs`.

Добавляйте новые серии в конец списка знаков при сборке, чтобы существующие сочетания в избранном сохраняли свои индексы. Дополняйте описание в `descriptions/round-02/` и при необходимости создавайте общий лист для сравнения. После изменений запускайте `node build.mjs` и проверяйте варианты в режимах «Конструктор», «Показ и сравнение» и «Продукт», включая читаемость в малом размере.
